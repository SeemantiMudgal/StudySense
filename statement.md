# StudySense – Project Statement

## Project Title

StudySense

## Problem Statement

Students often have to manage multiple subjects, assignments, deadlines, and study sessions at the same time. It can become difficult to keep track of completed tasks and understand how much time is being spent on each subject.

StudySense provides a simple command-line application to organize these study activities in one place.

## Proposed Solution

StudySense allows users to:

- Manage their subjects and study targets
- Create and manage study tasks
- Record study sessions
- Track subject-wise study time
- Monitor completed and pending tasks
- Generate a productivity report

The application stores data locally using JSON files, so no external database is required.

## Target Users

The primary users of StudySense are students who want a simple way to organize their academic tasks and monitor their study activity.

## Technologies Used

- Python
- JSON
- Command Line Interface
- Pytest for automated testing

## Main Python Concepts Used

The project applies:

- Functions
- Conditional statements
- Loops
- Lists
- Dictionaries
- File handling
- JSON data storage
- Exception handling
- Modular programming
- Input validation

## Expected Outcome

The expected outcome is a functional command-line study management application that allows users to organize academic tasks, record study sessions, and view basic productivity information.
